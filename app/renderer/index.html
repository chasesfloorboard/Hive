    Diagnostic session
    Start this before reproducing a problem. Reports stay local and redact music-library paths.
    Backend crash-course
    Run these in order while the session is active. Do not deliberately crash Hive; reproduce normal failures and audible glitches exactly as they happen.
    1. Baseline: let startup and the library scan finish; inspect the library normally.
    2. Transport: play, pause, resume, seek, previous, next, and let one track reach its natural end.
    3. Volume: slowly sweep down/up, rapidly sweep down/up, make small changes, mute/unmute, and change volume while paused and playing.
    4. Scrubber: click-seek, short drag, long drag, repeated drags, and release normally.
    5. Queue: reorder/select tracks and exercise several consecutive transitions.
    6. Persistence: verify volume/shuffle/repeat/queue/position, then restart Hive and confirm playback restores paused.
    7. Stress: scroll large library views, switch tabs/views, inspect artwork and queue while audio is playing.
    8. Finish: save the report and upload it here. The report correlates renderer actions with native GStreamer trace/state events.

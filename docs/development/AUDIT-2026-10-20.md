# Audit, 2026-10-20: desktop UI/UX, wiring, Hive Mobile sync

Three read-only audits of `main` (580338e plus the uncommitted Spotify/Apple
Music browse work in `app/renderer`) and `mobile` (9b7f30d). Line numbers are
approximate: they were taken from the working tree with that uncommitted work.
Every item was traced in code. Fixed items are on branch `hive-link-sync`
(desktop) and `mobile-sync` (phone).

## Fixed on hive-link-sync / mobile-sync

- **Hive Link playlists and remote control never worked.** The `getPlaylists` and
  `remote` options had been pasted into the `console.info('[MPRIS] artwork
  resolution', ...)` object instead of `createHiveLink({...})`, so
  `/api/playlists` answered `[]` and `/api/remote` 403. They're now in
  `createHiveLink`, guarded by a test in `test/hive-link.test.js`.
- **Phone Love was undone on the next app start.** The phone treated "staged"
  (waiting in Hive's inbox) as settled, and its next full sync copied Hive's old
  state back. The phone now keeps a staged change pending and resends it. Hive
  answers `staged`, then `unchanged` once the change is applied, or `stale`
  (with Hive's state) once it's discarded. Discarding records Hive's decision in
  `lastChangeAt`. Covered by a lifecycle test.
- **Tag editor, multi-file Save overwrote files with the first file's values.**
  This affected Sorting fields, track/disc totals and the option checkboxes,
  even when nothing was edited. They now merge across the selection like the
  other fields. A mixed checkbox shows indeterminate and is written only if
  clicked. See `test/tag-editor-selection.test.js`.
- **Tag-editor playback flags** (Exclude, Do not crossfade, Remember position)
  had no effect until a rescan, because `playbackSettingEnabled` built
  `DONOTCROSSFADE` instead of `doNotCrossfade`.
- **Disc # column was blank and didn't sort for scanned files.** The scanner
  stores `disk`, but the column read `disc`.
- **Find duplicates deleted copies beyond the 400 groups it lists.** Deletes now
  go to the Trash (`shell.trashItem`), and the dialogs say so.
- **Hidden Settings rows** (Hive Link pairing code, phone inbox) always showed:
  `#settings-modal .settings-row{display:flex}` beat `[hidden]`.

## Open: desktop bugs (ranked)

1. Unsaved tag edits are silently discarded when another song or album is
   clicked, or on ✕, Cancel or Escape. There's no "discard changes?" prompt.
2. Sorting by Album or Artist orders an album's tracks by title. The tie-break
   is title → artist → album, never disc/track; there's no multi-key sort and
   the sort isn't remembered.
3. Hive Link inbox is all-or-nothing. Love writes that fail are removed before
   `setLove` runs, and plays for unknown tracks are dropped silently. There's no
   pending badge outside Settings.
4. Smart playlist: "Refresh now" has no handler. `autoRefresh` and
   `exportStatic` are saved but never read, and Shuffle "Within selection" is
   ignored.
5. Dragging songs onto a sidebar playlist shows a drop target but does nothing.
   The drop handler only accepts `sidebar:` drags; songs are `beehive:N`.
6. Space toggles play/pause even when a button has focus. Hotkeys stop while
   Settings or the tag editor is open, though both are meant to stay open beside
   the app.
7. Playlist context-menu delete has no confirmation and leaves the sidebar entry
   behind. LIKELY: Favorites can be deleted.
8. The queue's context menu is the generic track menu: no "Remove from queue",
   "Play next" duplicates, and it acts on the main list's selection.
9. Lyrics search can put another track's lyrics in the editor: the stale-result
   guard uses `&&` where it needs `||`.
10. Unrated tracks show no stars, so they can't be rated by clicking.
11. There are no empty or no-results states (search, a first scan that finds
    nothing, Settings search).
12. Hive Link `/api/library` serves stale ratings and play counts. Ratings and
    plays go to `play-stats.json` only, never `library-cache-store`. `/api/info`
    has no library revision, and SSE sends only Love.
13. `OUTPUT_DEVICE_FALLBACK` from the helper is never shown: a chosen or
    bit-perfect output can silently fall back to the default.
14. LIKELY: overlapping config.json writes can undo a Settings change. Only
    `hivebee:saveSettings` takes `withJsonFileLock`; 12 other writers don't.
15. Smaller items:
    - `audio:integrity-repair-progress` has no listener.
    - MPRIS `OpenUri` is ignored.
    - Love and rating never reach MPRIS, Discord or the tray.
    - The ratings DB projection is missing.

In the uncommitted browse work:
- The Spotify "← Back" button can never show.
- The auto-tag cover picker can apply a cover different from the one shown, or
  a dead URL.
- `test/metadata-batch-coalescing.test.js` needs updating for `coverChoice`.

## Open: UX and accessibility

- Lists and context menus can't be driven from the keyboard (no roles,
  tabindex or arrow keys).
- Seek bar `step=0.01`; Repeat has no `aria-pressed`.
- Checkboxes have `outline:none !important`.
- `--text-dimmer` contrast is 3.6–4.3:1.
- Search:
  - is a raw substring over every field, including path and codec;
  - has no debounce, no Escape to clear, and no aria-label.
- Light theme forces `color-scheme:dark` on form controls.
- At 1024px and 150% zoom, the fixed-width player bar crushes the seek bar.
- Terminology is mixed: Love vs Favorites, US vs UK spelling, "Beehive" in UI
  text, and theme ids swapped against their labels.

## Missing features (S/M/L)

- Multi-key sort and "ignore The" (S–M); search syntax with AND/fields (M);
  Genres view (M).
- Queue toolbar: clear, save as playlist, remove, keyboard reorder (S–M).
- Reordering static playlists (M); playlist folders and PLS/XSPF (M); dropping
  files from the OS (M).
- Tag undo, copy/paste tags, tags-from-filename (M); auto-tag manual mapping (M).
- Cancel and undo for Convert, ReplayGain and Organise (M). Organise already
  keeps an undo log.
- Stop button and a visible "Stop after current" (S); keyboard rating and
  half-stars (S); shortcut cheatsheet (S).
- Hive Link: per-item inbox, pending badge, QR pairing (M).

## Hive Mobile and Hive Link sync

| Data | Today | Missing |
|---|---|---|
| Love | Two-way; phone changes go through the inbox | Fixed above |
| Star rating | PC→phone, during full sync only | Phone→PC, change log, newest-wins |
| Plays | Two-way through the inbox | Plays of PC-streamed songs aren't counted. PC plays for songs not yet on the phone are lost. The PC's absolute playCount is ignored |
| Skips | — | Both directions |
| Playlists | PC→phone, read-only | Two-way |
| Files | **Done (hive-link-sync / mobile-sync):** song sync both ways, automatic on Wi-Fi, deletions stay deleted | Delete propagation (deliberately not done) |

Phone tracks are keyed on MediaStore `_ID`, so a media DB rebuild orphans love,
rating and play rows. Matching is a fuzzy tag match (title, artists, ±12 s) with
no album or track number.

Phone, other:
- PC playlist rows have dead menus.
- No UI when READ_MEDIA_AUDIO is denied.
- Every rescan triggers a full library download and rematch.
- Any 401 silently unpairs the phone.
- Release builds are signed with the debug key.
